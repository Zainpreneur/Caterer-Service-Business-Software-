# Caterly — Frontend

React + Vite + Tailwind CSS single-page app for the Caterer Service Business Software.

See the [root README](../README.md) for full setup instructions.

## Quick start

```bash
npm install
cp .env.example .env
npm run dev
```

The app expects the backend API to be running (see `../backend`) and reachable at the URL configured in `VITE_API_URL`.
